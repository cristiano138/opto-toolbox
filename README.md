# 光电工具箱

一个装在手机/电脑上的离线小工具箱，专门算光学和光通信里那些常用的量。

**为什么做它**：这类"光电专业小计算器"在中文互联网上几乎没人做——不懂光的人不知道有这些公式，懂光的人又不写代码。我正好在中间：专业课在学，代码由 AI 帮写。做出来既是练手，也是将来递给导师和面试官看的作品。

**原则**：跟着课程走。这学期学到哪，工具箱就长到哪。大一先做能懂的，大二大三再补光纤、激光、光通信。

---

## 目录结构：哪能动，哪不能动

```
光电工具箱/
├── index.html        页面骨架（只改中间那两行注释之间的地方）
├── css/style.css     样式（颜色、字号、间距）
├── js/
│   ├── core/         ★ 引擎：utils / registry / ui / app —— 不要改
│   └── calc/         ★ 业务：一个计算器一个文件 —— 只在这里加东西
├── test.js           测试脚本（加完计算器跑一下）
├── bundle.py         打包成一个单文件 html（要发资料库时用）
├── manifest.json     装到桌面用的配置（图标、名字）
├── sw.js             离线缓存配置（加了新文件不用动它）
└── icon.svg / icon-192.png / icon-512.png   图标
```

一句话记住：**`js/core/` 是发动机，别碰；`js/calc/` 是货，往里加就行。**

---

## 加一个计算器的四步

1. **在 `js/calc/` 里新建文件**，文件名用英文，比如 `thin-lens.js`
2. **文件里写三件事**：这个计算器叫什么、有哪些输入框、公式怎么算
3. **去 `index.html`**，在「↓↓↓ 加计算器 ↓↓↓」那两行注释之间加一行：
   ```html
   <script src="js/calc/thin-lens.js"></script>
   ```
   （忘了这步，页面就找不到它）
4. **打开 `index.html` 看看**，再跑一次 `node test.js`

---

## 怎么测试

在这个文件夹里打开终端，输入：

```
node test.js
```

看到「0 项失败」就没问题。它会检查三件事：单位写法（4.7k、100n）能不能认、每个计算器有没有重名、用默认值算出来是不是 NaN。

## 怎么提交（存档）

用 GitHub Desktop：打开这个文件夹 → 左下角写一句话 → 点 Commit → 点 Push。
**每周至少提交一次**，GitHub 主页上那片绿点就是这么攒出来的，四年不断是很硬的履历。
